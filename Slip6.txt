Q1. Create a DataFrame containing the car model, engine size (in litres), and fuel efficiency (in km/L) 
for the given cars. Create a scatter plot to visualize the relationship between engine size and 
fuel efficiency.Add an appropriate title, label both axes, and use different colors for the 
data points.



import pandas as pd
import matplotlib.pyplot as plt

# Create DataFrame
data = {
    'Car_Model': ['Car A', 'Car B', 'Car C', 'Car D', 'Car E'],
    'Engine_Size': [1.0, 1.5, 2.0, 2.5, 3.0],
    'Fuel_Efficiency': [22, 20, 17, 14, 11]
}

df = pd.DataFrame(data)
print(df)

# Scatter Plot
plt.scatter(df['Engine_Size'],
            df['Fuel_Efficiency'],
            color='red')

plt.title('Engine Size vs Fuel Efficiency')
plt.xlabel('Engine Size (Litres)')
plt.ylabel('Fuel Efficiency (km/L)')

plt.show()







Q2. Use the Sports Performance dataset to develop a Simple Linear Regression model to predict 
Performance Score based on Training Hours Per Week. Evaluate the model using the R² score 
and plot a scatter graph with the regression line to visualize the relationship between training 
hours and performance score.



import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

# Create Sports Performance DataFrame
data = {
    'Training_Hours': [2, 3, 4, 5, 6, 7, 8, 9],
    'Performance_Score': [40, 45, 50, 55, 60, 65, 70, 75]
}

df = pd.DataFrame(data)
print(df)

# Input and Output
X = df[['Training_Hours']]
y = df['Performance_Score']

# Create and train model
model = LinearRegression()
model.fit(X, y)

# Predict performance
y_pred = model.predict(X)

# Calculate R2 Score
print("R2 Score:", r2_score(y, y_pred))

# Scatter Plot
plt.scatter(X, y, color='blue', label='Actual Data')

# Regression Line
plt.plot(X, y_pred, color='red', label='Regression Line')

plt.title('Training Hours vs Performance Score')
plt.xlabel('Training Hours Per Week')
plt.ylabel('Performance Score')
plt.legend()

plt.show()
