Q1. Write a Python program to create a DataFrame containing the attributes City, House_Type, 
House_Area, Number_of_Rooms, and Monthly_Rent. Apply the Normalization technique to the 
numerical attributes and display the normalized data.


import pandas as pd
from sklearn.preprocessing import Normalizer

# Create DataFrame
data = {
    'City': ['Mumbai', 'Pune', 'Nashik', 'Nagpur', 'Thane'],
    'House_Type': ['Flat', 'Bungalow', 'Flat', 'Row House', 'Flat'],
    'House_Area': [500, 1000, 600, 800, 700],
    'Number_of_Rooms': [1, 3, 2, 3, 2],
    'Monthly_Rent': [10000, 25000, 12000, 18000, 15000]
}

df = pd.DataFrame(data)

print("Original Data:")
print(df)

# Select numerical attributes
cols = ['House_Area', 'Number_of_Rooms', 'Monthly_Rent']

# Apply Normalization
scaler = Normalizer()
df[cols] = scaler.fit_transform(df[cols])

print("\nNormalized Data:")
print(df.round(4))





Q2. Generate a DataFrame containing customer information for Netflix and Amazon Prime users. 
Create a Venn diagram and a Pie chart to show the customers using only Netflix, only Amazon 
Prime, and both services. Add appropriate labels, colors, and titles to both visualizations.



import pandas as pd
import matplotlib.pyplot as plt
from matplotlib_venn import venn2

data = {
    'Netflix': ['Yes', 'Yes', 'No', 'Yes', 'No', 'Yes', 'No', 'Yes'],
    'Amazon_Prime': ['No', 'Yes', 'Yes', 'Yes', 'No', 'No', 'Yes', 'Yes']
}

df = pd.DataFrame(data)

# Count customers
netflix = sum((df['Netflix'] == 'Yes') & (df['Amazon_Prime'] == 'No'))
prime = sum((df['Netflix'] == 'No') & (df['Amazon_Prime'] == 'Yes'))
both = sum((df['Netflix'] == 'Yes') & (df['Amazon_Prime'] == 'Yes'))

# Venn Diagram
venn2(subsets=(netflix, prime, both),
      set_labels=('Netflix', 'Amazon Prime'))
plt.title("Venn Diagram")
plt.show()

# Pie Chart
labels = ['Netflix Only', 'Amazon Prime Only', 'Both']
values = [netflix, prime, both]

plt.pie(values, labels=labels, autopct='%1.1f%%')
plt.title("Streaming Platform Customers")
plt.show()
