Q1. Consider the following dataset representing the number ofstudents enrolled in different courses: 
courses = ["BCA", "BBA", "B.Com", "B.Sc", "BA"]
students = [60, 45, 75, 50, 35]
Create a Bar Chart to visualize the number of students enrolled in each course. Use different bar 
colors, add an appropriate title, and label both axes.



import matplotlib.pyplot as plt

courses = ["BCA", "BBA", "B.Com", "B.Sc", "BA"]
students = [60, 45, 75, 50, 35]

colors = ['red', 'blue', 'green', 'orange', 'purple']

plt.bar(courses, students, color=colors)

plt.title("Students Enrolled in Different Courses")
plt.xlabel("Courses")
plt.ylabel("Number of Students")

plt.show()







Q2. Create two DataFrames containing information about different mobile phones.
DataFrame 1: Brand, Model, Price, RAM
DataFrame 2: Model, Storage, Battery_Capacity, Operating_System 
Perform the following data transformation techniques:
a) Data Integration by combining the two DataFrames using Model
b) Label Encoding on the Brand attribute of the merged DataFrame
c) One-Hot Encoding on the Operating_System attribute of the merged DataFrame 
Display the original DataFrames, merged DataFrame, and transformed DataFrame.





import pandas as pd
from sklearn.preprocessing import LabelEncoder

# DataFrame 1
df1 = pd.DataFrame({
    'Brand': ['Samsung', 'Apple', 'OnePlus', 'Vivo'],
    'Model': ['A15', 'iPhone15', 'Nord', 'V30'],
    'Price': [15000, 60000, 25000, 22000],
    'RAM': [4, 8, 8, 8]
})

# DataFrame 2
df2 = pd.DataFrame({
    'Model': ['A15', 'iPhone15', 'Nord', 'V30'],
    'Storage': [128, 256, 128, 256],
    'Battery_Capacity': [5000, 3300, 5000, 4600],
    'Operating_System': ['Android', 'iOS', 'Android', 'Android']
})

print("DataFrame 1:")
print(df1)

print("\nDataFrame 2:")
print(df2)

# a) Data Integration
df = pd.merge(df1, df2, on='Model')

print("\nMerged DataFrame:")
print(df)

# b) Label Encoding
le = LabelEncoder()
df['Brand'] = le.fit_transform(df['Brand'])

# c) One-Hot Encoding
df = pd.get_dummies(df, columns=['Operating_System'], dtype=int)

print("\nTransformed DataFrame:")
print(df)
