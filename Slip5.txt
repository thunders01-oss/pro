Q1. Write a Python program to create a customer_DataFrame with suitable attributes such as 
Customer_ID, Gender, City, and Membership_Type. Perform label encoding technique on 
appropriate categorical attributes. Display the DataFrame before and after encoding.



import pandas as pd
from sklearn.preprocessing import LabelEncoder

# Create DataFrame
data = {
    'Customer_ID': [1, 2, 3, 4, 5],
    'Gender': ['Male', 'Female', 'Male', 'Female', 'Male'],
    'City': ['Nashik', 'Pune', 'Mumbai', 'Nashik', 'Pune'],
    'Membership_Type': ['Gold', 'Silver', 'Gold', 'Bronze', 'Silver']
}

df = pd.DataFrame(data)

print("Before Encoding:")
print(df)

# Apply Label Encoding
le = LabelEncoder()

df['Gender'] = le.fit_transform(df['Gender'])
df['City'] = le.fit_transform(df['City'])
df['Membership_Type'] = le.fit_transform(df['Membership_Type'])

print("\nAfter Encoding:")
print(df)





Q2. Generate a DataFrame containing customer information for Netflix and Amazon Prime users. 
Create a Venn diagram and a Pie chart to show the customers using only Netflix, only Amazon 
Prime, and both services. Add appropriate labels, colors, and titles to both visualizations.



import pandas as pd
import matplotlib.pyplot as plt
from matplotlib_venn import venn2

# Create customer DataFrame
data = {
    'Customer': ['A', 'B', 'C', 'D', 'E', 'F'],
    'Netflix': [1, 1, 1, 0, 0, 1],
    'Amazon_Prime': [0, 1, 0, 1, 1, 1]
}

df = pd.DataFrame(data)
print(df)

# Count customers
netflix_only = sum((df['Netflix'] == 1) &
                   (df['Amazon_Prime'] == 0))

prime_only = sum((df['Netflix'] == 0) &
                 (df['Amazon_Prime'] == 1))

both = sum((df['Netflix'] == 1) &
           (df['Amazon_Prime'] == 1))

# Venn Diagram
plt.figure(figsize=(6, 5))
venn2(subsets=(netflix_only, prime_only, both),
      set_labels=('Netflix', 'Amazon Prime'))

plt.title("Netflix and Amazon Prime Users")
plt.show()

# Pie Chart
labels = ['Only Netflix', 'Only Amazon Prime', 'Both']
values = [netflix_only, prime_only, both]
colors = ['red', 'blue', 'green']

plt.pie(values, labels=labels, colors=colors,
        autopct='%1.1f%%', startangle=90)

plt.title("Customer Subscription Distribution")
plt.show()
